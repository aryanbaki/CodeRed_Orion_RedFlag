# RedFlag logo

`redflag-original.png` is the original 1254 × 1254 transparent PNG supplied by the project owner. Preserve this source; no generative changes or upscaling were applied.

The extension uses size exports in `src/extension/icons` at 16, 32, 48, and 128 pixels. Its popup renders the 128-pixel export at 48 CSS pixels. The build copies the icon directory into the unpacked extension.

The detailed illustration is the approved brand mark. Any simplified toolbar variant requires a separate design decision. Dynamic grades are a separate behavior task and should retain the brand mark as the default/unknown identity.
