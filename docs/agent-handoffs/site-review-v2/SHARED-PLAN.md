## Fixed interfaces
Existing analysis command: {type:'redflag/analyze', mode:'one'|'all'|'recheck', pageKey, documentId?}. Use mode one with the exact current document ID; Analyze All uses recheck. Listen to redflag/state, and reject stale pageKey/document identity. Existing ReviewState, supportedAssessment, supportedDocumentGrade and summarizeReview remain the base source of UI data. Do not average grades or turn a community service grade into three policy grades.

Agent 3 exports buildSiteInsights(state: ReviewState): SiteInsights from src/core/site-insights.ts. SiteInsights shape: {summary:string, risks:Array<{documentId:string,kind:DocumentKind,finding:EvidenceFinding}>, benefits:Array<{documentId:string,kind:DocumentKind,finding:EvidenceFinding}>, coverage:'complete'|'partial'|'unknown'}. Benefits require separately validated protective quotes. Empty risks are not evidence of safety. Numeric summary subscores are omitted unless an explicit deterministic documented rule can justify them.

New chat command from trusted popup: {type:'redflag/chat',schemaVersion:1,pageKey:string,question:string,history:Array<{role:'user'|'assistant',text:string}>}. Response: {ok:true,schemaVersion:1,pageKey:string,answer:string,citations:Array<{documentId:string,sourceUrl:string,quote:string}>,model:string} OR {ok:false,schemaVersion:1,pageKey:string,code:string,error:string}. Question <=2000 characters; history <=10 messages of <=4000 characters; answer <=6000 characters; <=12 citations, each quote 12–4000 characters. Chat does NOT change grades. Route identity comes from trusted background state, never caller-supplied legal URLs/text. Chat history stays in memory and resets on site changes.

Server chat request at POST /api/chat: {schemaVersion:1,pageKey:string,question:string,history:Array<{role:'user'|'assistant',text:string}>,documents:AnalysisDocument[]}. <=6 deduplicated public policy documents, each obeying existing whole-document limits; no silent truncation. Aggregate JSON payload <=4,000,000 bytes; reject excess clearly. Background reuses verified retrieved documents transiently or safely refetches current discovered policies, preserving incomplete coverage. Missing/partial docs are disclosed, not described as complete. API-key credentials stay server-only; browser holds only the separate local demo access token in trusted extension contexts.

Agent 4 exports answerPolicyQuestion(request: ChatRequest, config: GeminiConfig, fetcher?: typeof fetch): Promise<ChatAnswer> from src/server/chat.ts. ChatAnswer: {schemaVersion:1,pageKey:string,answer:string,citations:Array<{documentId:string,sourceUrl:string,quote:string}>,model:string}. Source URL is server-derived from the matched submitted document ID. Exact quotes must be checked against that document. Unsupported answers, refusals and invalid output return typed failures, not fabricated fallback answers.

Agent 2 makes createAnalysisServer accept an optional injected ChatHandler and applies the same Origin/auth/consent-compatible transport limits to /api/chat. Tests inject a fixture handler. Primary reviewer wires answerPolicyQuestion into server/main.ts AFTER combining the private deliverables. Agent 2 owns background relay to /api/chat; Agent 4 does not edit background or HTTP router.
